# Uni-Hub: The Ultimate University Super App 🚀

**Uni-Hub** is a comprehensive digital ecosystem designed to streamline university life. It integrates essential student services into a single, high-performance platform, ensuring security, speed, and a seamless user experience.

## 🌟 Core Features

- **Digital Wallet:** Secure financial management with real-time transaction tracking.
- **Smart Marketplace:** A dedicated P2P hub for students to trade academic tools and supplies.
- **Localized Delivery:** Efficient logistics engine for on-campus and nearby services.
- **Student Housing:** A verified and curated database for safe student accommodations.
- **Sporting Hub:** Real-time match-making and facility booking system.

## 🛠️ Tech Stack

This project is built using a modern, scalable tech stack:

- **Frontend:** [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/) (For ultra-fast performance).
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Ensuring type safety and code reliability).
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/) (For a professional, responsive UI).
- **Backend/Database:** [Supabase](https://supabase.com/) (Real-time DB, Authentication, and Row Level Security).
- **Hosting&CI/CD:** Vercel (For global edge deployment and seamless updates).
